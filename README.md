# АНЯ · CRM

CRM для сопровождения клиентов: цели, планы и отчёты, программы и потоки, материалы, события, уведомления и отдельный личный кабинет клиента.

## Локальный запуск

Нужен Node.js 20+.

```bash
npm install
npm run local:crm
```

После запуска CRM открывается по адресу [http://127.0.0.1:3002](http://127.0.0.1:3002).

Чтобы заполнить новую локальную базу демонстрационными данными:

```bash
npm run local:fill-demo
```

## Проверки

```bash
npm run lint
npm run typecheck
npm run build
npm run db:concurrency-check
npm run telegram:test-outbox
```

## Данные и секреты

Локальная база, резервные копии, аватары, файлы окружения и автоматически созданные секреты исключены из Git. Не добавляйте в репозиторий файлы `*.db`, `.backups/`, `storage/`, `.env*` и `prisma/.local/`.

Локальный режим предназначен только для `127.0.0.1`. Для размещения на сервере нужны отдельные секреты, отключённый `LOCAL_AUTH_BYPASS`, защищённая база данных и настроенный Telegram-бот.
